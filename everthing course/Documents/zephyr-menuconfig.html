Opening menuconfig (Zephyr Kconfig)

Change firmware options interactively (blink period, shell, drivers). Saves to build/zephyr/.config.

Open menuconfig

app/

cd /home/jb/zeph-workspace/zephyr-course/app
west build -t menuconfig

app_OG/

cd /home/jb/zeph-workspace/zephyr-course/app_OG
west build -t menuconfig

First build (if needed)

west build -b nrf52840dk/nrf52840 .
west build -t menuconfig

Keys

KeyAction
↑ ↓Navigate
EnterOpen / select
SpaceToggle option
/Search (e.g. APP_HEARTBEAT)
SSave
QQuit

Project options

SettingEffect
APP heartbeat period (ms)LED blink speed
Shell menuCONFIG_SHELL and related
Our Driver / LED SensorCustom driver enable

After changes

west build
west flash

Or edit prj.conf

CONFIG_APP_HEARTBEAT_PERIOD_MS=1000
CONFIG_SHELL=y
