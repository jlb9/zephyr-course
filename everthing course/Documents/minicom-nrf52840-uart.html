Connecting to the nRF52840 DK with minicom

View UART output and run Zephyr shell commands for the LED sensor app (zephyr-course/app).
Serial: 115200 baud, 8N1, no flow control.

Prerequisites

  • nRF52840 DK connected via USB
  • Firmware flashed (west flash)
  • minicom installed: sudo apt install minicom

Step 1 — Find the serial port

ls -l /dev/ttyACM* /dev/ttyUSB* 2>/dev/null
dmesg | tail -20

Common device: /dev/ttyACM0 (use ttyACM1 if you have multiple boards).

Step 2 — Permissions (if needed)

sudo usermod -aG dialout $USER

Log out and back in if you see “Permission denied”.

Step 3 — Connect (quick start)

minicom -D /dev/ttyACM0 -b 115200

Press the board RESET button if nothing appears.

Step 4 — Save minicom settings (optional)

  1. Run sudo minicom -s
  2. Serial port setup → Device: /dev/ttyACM0, speed: 115200 8N1, flow control: No for both hardware and software
  3. Save setup as dfl or save a named profile (e.g. nrf52840)
  4. Exit, then run minicom or minicom nrf52840

Step 5 — Zephyr shell commands

Expected prompt:

uart:~$
CommandAction
sensor fetchTurn LED0 on (P0.13)
sensor readTurn LED0 off; print value
sensor infoDevice name and ready state
helpList commands

Example:

uart:~$ sensor fetch
fetch OK - LED on
uart:~$ sensor read
read OK - LED off, val=0.000000
uart:~$ sensor info
Device name : led_sensor
Device ready: YES
On boot, firmware blinks LED0 three times as a self-test, then waits for shell commands.

Troubleshooting

ProblemFix
No outputCheck device path; press RESET; close other apps using the port
Permission deniedAdd user to dialout (Step 2)
Garbled textUse 115200 8N1
west flash failsClose minicom first

cd /home/jb/zeph-workspace/zephyr-course/app

Exit with Ctrl+]. Close before flashing.

Workflow summary

  1. west build and west flash
  2. Close minicom before flashing
  3. minicom -D /dev/ttyACM0 -b 115200
  4. RESET if needed → run sensor fetch / read / info
